The pipeline

The data behind this page, and how much of it survived validation.

01

Extract

Throttled, cached calls to the OpenF1 API.

02

Validate

Pydantic checks every record; bad rows are rejected.

03

Clean

pandas removes out-laps and safety-car laps, adds a fuel correction.

04

Load

SQLite database, rebuilt each run with no duplicates.

05

Analyse

EDA produces every figure shown here.
